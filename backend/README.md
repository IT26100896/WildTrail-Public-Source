# Java backend

Run from the project root using `scripts/start-backend.ps1 -Build`; see the root README for setup. Open this `pom.xml` in IntelliJ, use JDK 17 and reload Maven.

## Configuration

| Environment | Purpose |
|---|---|
| SESSION_SECRET | Required, at least 32 characters; generated by setup |
| ADMIN_EMAIL / ADMIN_PASSWORD | First administrator provisioning only; password at least 12 chars |
| SPRING_DATASOURCE_URL | Defaults to persistent local H2, PostgreSQL mode |
| SPRING_DATASOURCE_USERNAME / PASSWORD | SQL credentials; local H2 defaults sa / empty |
| WILDTRAIL_DATA_DIR | Guide, audit and report files; defaults backend/data |
| SERVER_PORT | Defaults 8080 |
| SECURE_COOKIES | Set true for HTTPS deployment |
| APP_ORIGINS | Configure browser origin for deployment; see OriginGuard |

Next.js proxies /api to this Java service; it does not need the session signing secret. Bootstrap inserts catalogue samples only when destinations are empty. Existing accounts are not reset. First admin provision uses BCrypt; registration creates only customers.

SQL is authoritative for users, packages, vehicles, bookings, payments, reviews, messages and guide assignments. `resources.txt` is authoritative for guides. `reports/*.txt` are snapshots, not database restore files. `audit.txt` stores request metadata, without bodies/passwords/card data.

`modules/` holds six member domains; shared security/config/utility files are integration responsibilities. See `../team/` and `../docs/`.
